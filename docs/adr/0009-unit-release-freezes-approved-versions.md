# Publishing freezes a Unit Release that points at immutable Approved Lesson Versions

Lesson Versions are immutable copies captured at workflow moments (generation, before and after Regenerate, Submit, Approve, Restore); publishing captures none of its own. Publishing creates a Unit Release referencing each Lesson's Approved Version. Reopening and editing a Lesson changes only the working document; the Release is unchanged and the Unit shows Unpublished Changes until it is published again. This makes "Approved" mean a specific, auditable text, which state review requires.

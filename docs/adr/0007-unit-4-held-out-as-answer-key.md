# Example Lessons come only from Units 1–3; published Unit 4 is held out as the Answer Key

Newsela's published Unit 4 is the same Unit as the sample Outline. Putting any of it in a prompt would let the model copy it and make the output look good for the wrong reason, so few-shot examples (one per Lesson Type) are drawn only from published Units 1–3, and Unit 4 is used solely by an offline comparison report. A test asserts that no Answer Key material can enter a prompt.

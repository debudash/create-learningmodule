# The official standard code wins; Outline errors go to a person at import and are never auto-corrected

When an Outline's standard code and its written description disagree, the Lesson teaches the official text of the code, and the import preview raises the conflict: non-existent or malformed codes are Blocking Outline Issues, description mismatches are Warnings with a suggested code, and an Editor decides. Standard tags go into state review, so a code must mean its official text, and changing an instructional designer's intent is a human decision.

## Considered Options

- **Description wins (auto-correct the code)**: silently rewrites the designer's work.
- **Pass both to the model**: pushes an unresolved contradiction into every generated Lesson.

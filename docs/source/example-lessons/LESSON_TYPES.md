Column notes:
- **Type** is the lesson object's `type` field as published.
- **Outline type** maps it to the Sample Unit Outline vocabulary (`docs/source/sample-unit-outline/`). Spark N = lesson N. Writing lessons after the End Unit Assessment are counted as Showcase "Writing". Investigation Writing lessons next to another Writing lesson are marked "Core Writing (Double Lesson)?" because the platform has no double-lesson tag; this is an inference from adjacency. Flex Day = End-of-Arc Flex Day (every published Flex Day in Units 1 to 3 is a "Skill-Based Huddles" day). Research, Presentation and the two assessments have no outline equivalent and are left blank.
- **Sections** are the teacher sections in order with minutes (`estimated_time_in_minutes`); LIA = Learning in Action. Homework has no minutes.
- **ELD / AddS** = number of "Integrated ELD Instructions" / "Additional Student Support" collapsibles. **PC** = "Pulse Check" mentions in teacher sections. **SR** = text runs in the sample-response colour `#720780`.
